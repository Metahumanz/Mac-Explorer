# Phase 4C：详细信息列配置

日期：2026-10-20。用户要求“提交，然后4c”；4A/4B 已提交为 `a0a248d`，4C 基于该提交开发。仅实现名称、修改日期、创建日期、类型、大小五列配置，不增加任意元数据属性列。

## 实现范围

- 表头右键及“查看 → 列”提供显示/隐藏和恢复默认；名称列保持可见。通过原生表头拖动改变顺序和宽度，保留表头排序入口。
- 旧偏好不需迁移写入，继续使用 Phase 2 的响应式默认布局。用户配置后完整保留所选列和宽度，窄窗口或打开窗格时横向滚动；窗口自动收起/适配结果不写入用户配置。恢复默认列只恢复当前文件夹列布局，不改变排序及其他视图设置。
- `defaultFolderView` / `folderViews` 增加独立 `columns` 组，避免只有列配置的记录被旧的布局/排序判断删除。继承全局默认，允许文件夹覆盖，保留 5,000 项上限及跨窗口/重启恢复。“应用到所有文件夹”包含列配置；设置页更改默认布局/排序时保留列组。
- `DetailColumns` 只接受五个已知列标识，补齐缺失标识、去重、强制保留名称；未知版本回退继承。非法、非有限或超范围列宽使用默认值，列宽上限 2,000 点。偏好数据不操作文件内容或文件日期。
