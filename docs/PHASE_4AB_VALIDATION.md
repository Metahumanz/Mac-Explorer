# Phase 4A / 4B：常用 SMB 连接与恢复

日期：2026-10-20。用户明确授权“先做 4A、4B”，基于 Phase 3 提交 `0dd7470` 实施。4C 列配置未开始。本阶段已按用户要求纳入本地提交收尾；未推送、未安装替换；真实共享没有挂载、断开、写入或文件读取操作。

## 4A 实现与验证范围

- 在原有网络页增加常用连接及添加、编辑、移除入口；对话框只输入名称和服务器地址。名称最多 120 字符、记录最多 100 条，避免无界偏好数据。
- `SavedSMBConnections` 仅保存 ID、显示名、验证后的 SMB 地址；拒绝 URI 用户名/密码、查询参数、控制字符和无效协议，不保存密码、运行状态或本地挂载路径。统一主机大小写、默认端口和尾斜线，保留路径大小写及非默认端口。重复地址报错，编辑按 ID 写入当前最新列表，避免覆盖其他窗口新增的记录。
- 启动与恢复只展示记录，不自动连接。用户点击后仍通过系统 NetFS 认证，使用系统返回的实际路径，不按显示名称拼接 `/Volumes/...`。即使按钮显示“打开”，也由系统重新核验目标，避免凭旧路径直接进入同名的其他挂载。
- 偏好变更同步到同一偏好域的网络页，移除只删除收藏记录，不推出磁盘或删除文件。损坏、重复或不安全的偏好记录在读取时忽略，启动读取不自动重写用户设置。

## 4B 实现与验证范围

- 网络页、地址栏和“连接服务器”入口共用 `SMBConnectionSession`，统一单次连接、错误和取消状态；网络页使用原有内联按钮，其他入口显示延迟出现的可取消进度窗。
- 取消请求未完成时继续保持忙碌和防重入，等待系统实际结果。若系统最终成功挂载，不误报取消成功，也不因用户已取消而强行导航；不擅自卸载已建立的连接。
- 常用项区分待连接、正在连接、已挂载、未挂载、读取失败和连接失败，并提供显式重新连接。成功连接与文件传输成功分开，不重放剪切、粘贴、删除或撤销。
- 挂载关联只保留在当前进程。内核缓存中的挂载 ID 用于识别同一挂载的晚到通知和同路径替换；不读取挂载来源账号/地址。唤醒或身份未知时回到待验证状态，不能据此猜服务器身份。每次打开仍经系统确认，内核挂载 ID 也不作为文件传输安全凭据。
- 磁盘读取版本不能覆盖之后建立的新连接；未知分类/读取失败不等同于已卸载。确认挂载消失后清除旧的“已连接”提示，刷新失败不伪造零容量。
- 晚到连接成功不能覆盖后续目录导航，也不打断正在执行的文件操作、重命名或确认对话框。失败保留原标签位置、选择、剪贴板和源文件。
