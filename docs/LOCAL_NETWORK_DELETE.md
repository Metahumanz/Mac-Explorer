# 本地网络删除版本

- 分支：`codex/local-network-delete`；基于上游 v1.5.0（`1aa67b6`）。
- 本地版本：1.6.0；仅用于本机安装，未发布 GitHub Release。
- 恢复网络永久删除入口，必须确认，默认焦点为取消；本地删除继续进入回收站。
- 删除引擎保留实际父目录 FD 分类、确认快照、身份校验、部分删除结果和上游硬链接处理；本地批量删除不受网络 64 项限制。
- 最终身份检查与 unlinkat 之间仍存在竞态：其他程序同时替换条目时不能保证不误删。此限制已在网络删除确认中显示，不宣称原子删除。

## 验证

- 核心专项：NetworkDeletionChecks 51、FileActionChecks 231、TrashChecks 59，通过；竞态检查用于复现已知限制。
- 隔离验证构建完整 UI smoke：642 项通过；SVN UI 因缺少 svn/svnadmin 跳过。
- 安装版界面回归：报告 59 项，网络测试注入 1 项按生产构建边界跳过，其余通过；网络删除路径已由隔离构建覆盖。
- 本地化检查：590 条字符串通过。
- 普通生产构建通过；符号检查确认不存在 PreparedDeletion.fixtures / NetworkDeletion.auditHook。
- 删除测试只用本地临时夹具；本轮没有操作真实 NAS 数据，未补齐 macOS 13 / 真实 SMB 删除验收。

## 安装和后续更新

使用原生离线安装入口校验 ZIP SHA-256、签名、架构和版本，并原子替换 `/Applications/Mac Explorer.app`。安装前正常退出并保留窗口，安装后核对偏好哈希和程序哈希。

这是本地定制构建。官方自动更新可能覆盖本次网络删除功能；由于版本比较，版本号不高于 1.6.0 的官方包不会自动替换此版本。
