## 本轮修订

撤回此前自定义的多轮 SHA-256、扩展属性摘要、来源隐藏改名、阶段 JSON 及额外 fsync 流程。先前 650 项核心检查只证明旧版设计在本地通过，不能用于证明本次修订后的源码。旧实现和当时文档已保存在忽略目录 `native/output/validation/phase1-before-windows-alignment/`，旧运行日志仍在 `phase1-20261020T002836Z/`。

当前代码：

- 同卷优先排他重命名；普通复制和跨卷复制使用 macOS `copyfile`，允许系统 clone，复制原生数据、stat 和扩展属性。系统回调提供实际复制字节和取消，不额外完整读取文件计算哈希；结果也不标称内容校验和已验证。
- 建立来源及目标元数据清单，检查类型、大小、链接、身份和来源变化；按后序恢复创建/修改日期并重新读回。SMB/NTFS 使用 100 ns 表示精度，FAT 按已知创建/修改精度；其他未知情况不扩大容差。
- 属性无法保留时，UI 提供重试、明确仍然复制/移动、跳过、取消。仍然移动会说明将移除来源且可能丢失属性。用户接受后完成结果保留警告；无交互调用默认跳过。
- 来源保持原名称，最终目标确认后才按已验证清单清理。每次清理前检查目标和来源身份；清理失败可在当前操作内重试，未知新增项目不递归删除。失败或取消的剩余来源仍在原位置。
- 取消/失败先清理本次私有暂存副本；只有权限、父目录变化等导致清理失败时保留并报告路径。无日常阶段日志、隐藏来源或无条件保留失败副本。
- 剪贴板和撤销仅消费完成移动；跳过、失败及未执行项保留。撤销及回收站还原复用控制和日期恢复，已完成但带警告的还原仍清理相应来源记录。
- 冲突可重试、保留两者、跳过或取消，不覆盖既有目标。没有新增替换、目录合并或完整传输队列。
- 传输窗口延迟 300 ms 显示，支持取消；属性窗口仍使用统计结束后的新一次日期读取。主界面布局和现有设置不变。

## 限制及未验收项

- 依赖系统复制成功及轻量检查；不能承诺检测系统未报告、大小/元数据未变的同长度内容损坏。没有完整内容校验和，也没有把这种取舍伪装成 Windows 的内部算法。
- 文件系统精度差异按明确表示规则处理；两个共享的专用种子已验证日期设定及延迟读回，但真实传输首项阻塞；服务器原生时间映射或落盘尚未验收。普通复制与跨卷移动的创建日期规则也没有 Windows 11 实机对照证据，继续以用户原始日期保留目标为准。
- ACL 使用目标原生继承语义，没有跨平台逐项 ACL 等价保证；硬链接测试证明内容和安全清理，没有证明硬链接拓扑或稀疏分配完全一致。
- 目录清单仍占用内存，元数据检查仍产生 stat/目录 I/O；尚未做大文件/大目录性能基准。系统调用阻塞时取消可能等待系统返回。
- 取消不会回滚批次中已经完成的项目。清理阶段可能部分完成；剩余来源留原位置、目标可能也存在，新操作仍可能遇到同名。没有跨进程续传、自动恢复或启动清理；进程崩溃仍可能留下暂存项。
- 身份复核降低误覆盖/误删风险，不能构成跨卷原子事务，也不能阻止其他程序在最后一次检查后改写或删除目标。
- 特殊节点、树内其他设备及层级过深仍安全拒绝。没有擅自扩大为 NAS 挂载管理、物理断连、系统默认项、替换安装、Phase 2/3 或发布。
- 真实 SMB 仅执行到首项失败，完整矩阵未通过。未运行 XCTest、真实 Windows 11 对照、真实写满/断连、进程终止恢复、macOS 13 实机或大文件压力测试。
