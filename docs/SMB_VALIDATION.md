## 结论

**尚未通过 SMB 传输验收。** 第一项“本地 → passport 普通复制”已复制数据并完成日期恢复/读回，但在最终排他提交之前返回 `Operation not supported`。返回项为 `failed / systemCopy`，`datesVerified: true`，`contentVerified: false`，最终目标不存在，原来源存在且内容、原始日期均未变化。传输流程已清理本次不完整副本，无恢复暂存路径。

结合 `VerifiedTransfer.perform` 的执行顺序，错误定位在最终 `renameatx_np(RENAME_EXCL)` 提交路径的 SMB 兼容环节。当前实现缺少该环节返回不支持时的兼容处理；不能根据本地 APFS 回归通过认定此路径在 SMB 可用。尚未添加业务修复或绕过保护继续删源。

两个共享上的独立 2 字节种子文件均成功设置并延迟读回创建、修改日期，原始数值和 SHA-256 与建立时一致。这只证明本轮 macOS 客户端对这些夹具的读写结果，不代表跨共享移动完成、Windows 客户端显示一致、服务器原生 NTFS 属性或掉电持久性已经验证。

按“异常停止并保留现场”的方案停止了矩阵。两共享双向剪切、同共享移动、碰撞、目录及空文件实际 NAS 测试尚未执行，第二轮目录未创建。NSSD 不能记作传输通过。
